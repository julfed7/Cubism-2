# 🧟 CUBISM 2

> 2D top-down шутер на **Godot 4** с зомби, лутом, суперспособностями бойцов и онлайн-матчами до **20 игроков**.

Выживай в одиночной кампании или заходи в онлайн: классический бой, королевская битва со сжимающейся зоной и захват кристаллов. Лутай сундуки, прячься в кустах, копи заряд супера и не дай зомби добраться до тебя первым.

## ✨ Особенности

- **3 режима игры** — классика, королевская битва, захват кристаллов
- **3 карты** — `Island`, `City`, `CrystalArena`
- **Одиночная кампания** и **онлайн-мультиплеер** (до 20 игроков в комнате)
- **Боты-зомби** с навигацией по карте (`NavigationAgent2D`) и обходом друг друга
- **5 видов оружия**: пистолет, SMG, дробовик, винтовка и ближний «Кристальный клинок»
- **Инвентарь на 9 слотов**, магазины и запас патронов под каждый ствол, аптечки
- **Сундуки с лутом** и выпадение снаряжения при смерти игрока
- **Бойцы с уникальной суперспособностью** (Shelly, Colt, Spike)
- **Стелс**: в кустах игрок становится полупрозрачным, а HUD показывает уровень обнаружения зомби
- **Прогресс**: трофеи, монеты, победы и число матчей сохраняются между запусками
- **Звуковое оформление**: музыка матча, UI-звуки, разные шаги по траве, камню и дереву
- Поддержка **виртуального джойстика** для мобильных устройств

## 🎮 Режимы игры

| Режим | Время | Цель |
|---|---|---|
| **Классический** | 150 с | Выжить и продержаться до конца матча |
| **Королевская битва** | 210 с | Остаться последним. Зона сжимается с 1200 до 260 м, вне её игрок получает урон. Респавна нет |
| **Захват кристаллов** | 120 с | Собери **10 кристаллов** раньше окончания времени. Захваченные кристаллы появляются снова через 3 секунды. Игроки стартуют с Кристальным клинком |

В классическом режиме и режиме кристаллов после смерти работает **респавн через 5 секунд**.

## 🔫 Оружие и предметы

| Оружие | Тип |
|---|---|
| `pistol` | Стартовое оружие (с 24 патронами) |
| `smg` | Автоматическое |
| `shotgun` | 8 дробин веером ±15° |
| `rifle` | Дальнобойное |
| `crystal_blade` | Ближний бой, урон 26 |

- Без оружия или с пустым магазином игрок бьёт в ближнем бою (урон 15 / 10 с оружием в руках)
- Аптечка восстанавливает **50 HP**
- Предметы лежат в **сундуках** (в каждом минимум одно оружие и один расходник) и выпадают из убитых игроков

## 🦸 Бойцы и суперспособности

Супер заряжается от нанесённого урона и активируется кнопкой `super_ability`.

| Боец | Суперспособность |
|---|---|
| **Shelly** | Мощный урон конусом перед собой (55) с отбрасыванием |
| **Colt** | Серия усиленных выстрелов веером (урон ×1.6, скорость пули ×1.25) |
| **Spike** | Лечит себя на 40 HP и бьёт всех врагов вокруг (38) |

| Действие | Управление |
|---|---|
| Движение | Стрелки (действия `ui_left/right/up/down`) или виртуальный джойстик |
| Прицеливание | Мышь |

| Перезарядка | `R` |
| Использовать предмет / выбрать слот | `E` |
| Выбор слота | `1`–`9` |
| Смена оружия | Колесо мыши |
| Суперспособность | Действие `super_ability` |

## 🌐 Мультиплеер

Игра использует **авторитарного хоста**: один из игроков создаёт комнату, остальные подключаются к нему.

- **Матчмейкер** на WebSocket: создание комнаты, поиск матча, уведомления о закрытии комнаты
- **[Noray](https://github.com/foxssake/noray)** для NAT punch-through с автоматическим fallback на relay
- **ENet** (`ENetMultiplayerPeer`) для игрового трафика
- Лобби со списком игроков и стартом матча хостом

### Сетевая архитектура

- Хост — источник истины: обрабатывает стрельбу, подбор предметов, открытие сундуков, ближний бой, супер и захват кристаллов
- Клиенты отправляют лишь **запросы** (`request_move`, `request_shoot`, `request_action`), а хост их валидирует (дистанции, наличие оружия и патронов, скорострельность)
- **Снапшоты состояния ~30 Гц** для игроков и зомби
- **Interest management**: клиент получает только сущности в радиусе 800 единиц
- **Адаптивная частота репликации**: чем ближе сущность к игроку, тем чаще она синхронизируется
- **Интерполяция и экстраполяция** (trajectory buffer) для плавного движения удалённых игроков и зомби
- **Квантование позиций** для экономии трафика
- Спавн через `MultiplayerSpawner` (игроки, пули, предметы, сундуки, кристаллы)
- Поздно подключившиеся клиенты получают снапшот текущего мира

```
scripts/
├── Автозагрузки (Autoload)
│   ├── GameState.gd        # Ник, выбранный боец, трофеи, монеты, победы; сохранение в user://settings.cfg

│   ├── health.gd           # Компонент здоровья

│   ├── chest.gd            # Сундуки и таблица лута
│   ├── pickup.gd           # Подбираемые предметы с физикой выброса
│   └── player_spawn.gd     # Маркер точки появления
│
└── Интерфейс
    ├── menu.gd             # Главное меню и профиль игрока
    ├── level_select.gd     # Выбор уровня одиночной кампании
    ├── create_room.gd      # Создание комнаты
    ├── join_room.gd        # Поиск матча
    ├── lobby.gd            # Лобби
    ├── settings.gd         # Ник и громкость музыки, эффектов, шагов
```

## 🚀 Запуск

### Требования

- **Godot 4.3+** (используются `TileMapLayer`, типизированный GDScript, `MultiplayerSpawner`)
- Аддон **Noray** (клиент и `PacketHandshake`)

### Шаги

```bash
git clone https://github.com/<your-name>/<your-repo>.git
cd <your-repo>
```

1. Открой проект в Godot (`Import` → выбери `project.godot`)
2. Убедись, что в **Project Settings → Autoload** подключены: `GameState`, `NetworkManager`, `UISoundManager`, `SettingsManager`, `BrawlerDB`, `ItemDB`, `MapManager`, `Noray`
3. Нажми **F5**

### Проверка мультиплеера

Запусти несколько экземпляров игры (**Debug → Run Multiple Instances**): один создаёт комнату, остальные нажимают «Найти матч».

### Настройка сервера

Адрес матчмейкера и Noray задаются в `NetworkManager.gd`:

```gdscript
const NORAY_HOST: String = "your-noray-host"
const NORAY_PORT: int = 8890
var matchmaker_url: String = "wss://your-matchmaker-url"
```
